# Noosnote à plusieurs

Ouvre un Noosnote puis **Partager** pour en faire un espace commun. Seul cet espace et ses pièces jointes sont copiés dans un dépôt privé dédié. Les autres Noosnotes restent personnels. La copie personnelle est conservée en sauvegarde, et l’espace partagé prend sa place dans la barre latérale.

Si GitHub demande une configuration, crée le dépôt privé proposé avec un README, puis autorise Noosphere sur ce dépôt dans les réglages de l’application GitHub. Reviens dans Noosphere et choisis **Vérifier et continuer**.

Dans **Partagé → Membres**, le propriétaire peut ouvrir les accès GitHub, inviter les collaborateurs et copier le lien de l’espace. Le destinataire accepte l’invitation avec son compte GitHub, puis colle le lien dans **Rejoindre un Noosnote**. Les espaces accessibles sont aussi recherchés au démarrage parmi les 100 dépôts les plus récemment mis à jour.

Les droits proviennent de GitHub : propriétaire, éditeur ou lecteur. Sur un dépôt personnel, les collaborateurs ont un accès en écriture ; les droits de lecture seule dépendent du type de dépôt et des permissions GitHub. Le lien seul ne donne aucun accès.

Le texte peut être modifié à trois personnes ou davantage. Les modifications concurrentes sont fusionnées avec Yjs. La synchronisation passe par GitHub toutes les 15 secondes quand l’espace est ouvert ; Ctrl / ⌘ S la déclenche immédiatement. Les avatars affichent les membres, sans prétendre indiquer une présence en direct. Une modification hors ligne reste enregistrée sur la machine et rejoint les autres à la reconnexion.

Les changements de structure, de titre ou de tables utilisent également la fusion à trois versions. Si deux modifications sont incompatibles, Noosphere conserve les deux versions et propose une comparaison avant de choisir.

Le panneau **Discussions** permet de commenter la page, répondre, mentionner un membre avec son identifiant GitHub, résoudre ou rouvrir une discussion. Pour citer un passage, sélectionne-le avant d’ouvrir les discussions. Le filtre **Pour moi** retrouve les mentions sur la page ouverte. Chaque membre choisit son pseudo dans l’espace ; son identifiant GitHub reste visible.

L’onglet **Historique** ouvre les changements publiés dans GitHub. Les brouillons locaux y apparaissent après synchronisation. Les PDF, images et documents Word utilisent le dépôt partagé et restent accessibles avec les mêmes droits que les pages.

Le stockage distant est celui d’un dépôt GitHub privé ; les collaborateurs autorisés peuvent en lire les fichiers et l’historique. Les caches locaux utilisent le stockage sécurisé de Noosphere et sont séparés par compte et dépôt. Fermer la fenêtre ou se déconnecter attend l’enregistrement des brouillons personnels et partagés.
