# Fichiers de version

[English](README.md) | **Français**

Les installateurs Windows, les paquets Linux et leurs sommes de contrôle sont
produits pour chaque version.

- `windows/` contient l’installateur NSIS, l’exécutable portable et
  `SHA256SUMS.txt`.
- `linux/` contient l’AppImage, le DEB, le RPM, les instructions Linux et
  `SHA256SUMS.txt`.

Les exécutables Windows ne sont pas signés avec un certificat Authenticode.
SmartScreen peut afficher un avertissement au premier lancement.
